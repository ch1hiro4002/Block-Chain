# Block-Chain

一个使用 Go 编写的轻量级区块链项目，实现了签名交易、交易池、链接并签名的区块、简化的权益证明出块、基于 TCP 的区块同步，以及一个小型栈式虚拟机。

> 本项目为演示项目，不适合生产环境。

## 已实现功能

- 基于 ECDSA P-256 的密钥、地址、交易签名和区块签名
- 支持重复检测、nonce 校验和有效期的交易池
- 使用 SHA-256 链接区块，并校验区块签名和 proposer
- 简化版 PoS 验证者集合，按质押权重选择区块提议者
- 按区块高度保存验证者集合快照，保证后加入节点能正确校验历史区块
- 基于 TCP 的长度前缀消息传输和 `gob` 编码
- 节点间区块同步和验证者集合同步
- 小型栈式虚拟机，支持算术运算、字节打包和内存键值状态

## 快速开始

构建并运行演示：

```bash
make build
make run
```

运行测试：

```bash
make test
```

演示程序会启动三个节点：`LOCAL`、`REMOTE` 和稍后加入的 `LATE`。`LATE` 会连接种子节点，同步区块和验证者历史，然后参与后续出块。

## 项目结构

```text
.
├── core/       # 交易、区块、区块链、验证者、虚拟机、状态、编码
├── crypto/     # 密钥、签名、地址
├── network/    # TCP 传输、RPC、服务端、交易池
├── types/      # 哈希、地址等通用类型
├── docs/       # 文档
└── main.go     # 演示入口
```

## 核心组件

| 组件 | 说明 |
| --- | --- |
| 交易 | 带签名、nonce 和有效期的数据负载，当前作为虚拟机字节码执行 |
| 区块 | 包含区块头、交易列表、proposer 地址和区块签名 |
| 区块链 | 基于内存的哈希链接链，并在写入前验证区块 |
| 共识 | 简化 PoS：按质押权重选择 proposer，并按高度保存验证者集合 |
| 网络 | TCP 节点之间同步状态、区块、交易和验证者快照 |
| 虚拟机 | 最小栈式执行环境，支持算术、字节打包和状态存储 |

## 当前限制

- 验证者成员通过节点同步加入，而非由链上质押交易治理
- 没有惩罚、最终性、分叉选择或完整的多验证者共识
- 区块链和状态仅保存在内存中
- 没有节点发现、身份认证或生产级网络安全机制
- 虚拟机没有 gas 计量和执行限制
